# POSMT - Multi-Terminal Point of Sale Management System

One Store. Multiple Terminals. Centralized Management.

A retail POS system where multiple cashier terminals share one product catalogue, inventory and database.

## Tech Stack

- Frontend: React.js, Bootstrap
- Backend: C#, ASP.NET Core Web API (.NET 10)
- Database: SQL Server, Entity Framework Core
